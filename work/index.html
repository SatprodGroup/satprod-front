Le Royal TervurenResidential real estate

A connected residence, from the website to the wiring

Le Royal Tervuren is a high-end residential building, with interiors by YOO designed by Philippe Starck. We delivered four projects for it, from marketing the apartments to running the building day to day.

The challenge

Present the building to prospective buyers, then give management and residents the tools and infrastructure a modern residence needs: requests, communication, telephony, TV and access control.

What we did

  • Website: multilingual presentation site with the building history, a virtual tour, the apartments, the interior design and the services.
  • Building management app: tickets per apartment with priority and progress tracking, messages to residents, a residents list and an address book.
  • Network infrastructure: rack with managed switches and Cat 6 patching, fibre internet access, an IP telephone system, TV distribution and a UPS.
  • Video door entry: video entry panel at the street door and its control electronics.

Technologies

  • Multilingual website
  • Bootstrap
  • Cisco SG500 switches
  • Cat 6 cabling
  • Fibre access
  • Panasonic KX-NCP500 IP-PBX
  • VoIP
  • TV / IPTV distribution
  • Eaton UPS
  • BPT video door entry

Galaxy StudioMusic and audio production

Remote sessions and custom hardware for a recording studio

Two projects for a recording studio: software to bring remote musicians into a session, and a dedicated hardware remote.

The challenge

Let artists and engineers work together from different places, and control studio functions from a physical remote instead of a screen.

What we did

  • GS-Streamer: desktop application that sends a camera feed and two audio inputs to the studio, plays the return mix on the local outputs, and receives its settings from the server so the musician only has to press Start.
  • Studio remote: custom remote with push buttons and LED feedback, from the schematic to the wiring.

Technologies

  • macOS desktop app
  • Live audio streaming
  • Live video streaming
  • Arduino
  • Custom electronics
  • Schematic design

SyspeoConnected devices

A Wi-Fi device, from schematic to firmware

Hardware and embedded software for a connected product.

The challenge

Turn a product idea into working hardware that joins the local Wi-Fi network and can be found without manual setup.

What we did

  • Electronics: schematics for the device and its connections.
  • Firmware: embedded software in C with Wi-Fi connectivity, stored network profiles and zero-configuration networking, so the device announces itself on the local network.

Technologies

  • C
  • Microchip TCP/IP Stack
  • Wi-Fi
  • Zeroconf (link-local, mDNS)
  • Schematic design

SAE InstituteEducation

Online tools for a creative media school

A course platform and an assignment workflow for a school teaching audio, film, web and games.

The challenge

Sell short and professional courses online in several languages, and manage the flow of student assignments between students, supervisors and head instructors.

What we did

  • SAE Online: course catalogue across audio, film, web and games, filtered by course language, level, start date and duration, with prices and online enrolment.
  • Submission System: students hand in their assignments online; supervisors correct them, track each attempt and send feedback; head instructors get their own overview.

Technologies

  • Web application
  • Multilingual (EN, ES, DE)
  • Search filters
  • User roles and authentication

Unbend RecordsMusic

A studio and an online showcase for a record label

The technical installation of the label's studio, and the website that presents its releases.

The challenge

Equip the label's recording studio, and give its artists and releases a home online.

What we did

  • Studio: technical installation of the control room, with the mixing desk, monitoring, audio and network cabling.
  • Website: discography browsable by album, showing the service delivered for each release (recording, mixing, private concert), with studio and contact pages.

Technologies

  • Studio installation
  • Audio cabling
  • Network cabling
  • Website
  • Discography catalogue

P.V.I.Residential

Seamless Wi-Fi across a large apartment

A wireless mesh network designed from the floor plan.

The challenge

Provide reliable Wi-Fi in every room of a large apartment.

What we did

  • Coverage plan: the floor plan split into coverage zones, with one access point placed per zone.
  • Mesh network: access points deployed and configured as a single mesh, so devices stay connected while moving from room to room.

Technologies

  • Wireless mesh
  • Open Mesh access points
  • Coverage planning
